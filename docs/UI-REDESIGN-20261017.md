## 1. 逐屏评审（现状问题）

来自 `shots/` 8 张实机截图（2026-10-16 mapgen 版）：

| 屏 | 问题 |
|---|---|
| title | 全屏均匀灰遮罩（150α）把战场压成一片灰；标题两字裸排无层次；五按钮同宽同灰，主按钮是唯一兴奋点；tips 弹出即挤进按钮列 |
| game | 顶栏信息裸排：血条/波次/供给/热层/暂停无分组；血条单一绿块无底衬无刻度；右侧 8 钮一列全同款，选中态仅底色差异 |
| heat | 热层色块本身清楚，但顶栏按钮与模式列同为 issues 同上 |
| slots | 与暂停/设置共用同一张灰卡；槽位"空/可读/损坏"仅靠文字区分；删除钮小 |
| settings | 同一张灰卡；滑杆、开关、标签裸排无对齐网格 |
| gameover | 胜负仅标题换色；统计行小、无层级；胜负卡完全同构，情绪弱 |
| pause | 同灰卡 |
| narrow / 20:9 | 结构正常（D1-5 已过），本次改版保持该约束 |

全局：卡片 = flat 圆角 + 1px 边框；按钮 = 三态仅提亮；无投影、无装饰、无 hover 位移——"程序员风"。

## 2. 设计原则

1. **题材叙事**：沙漠沙 + 运河水。交互主色 = 运河青绿（你造的是水路），经济色 = 琥珀金（供给/赏金），危险红、警戒黄保留。
2. **一次一刀**：改样式 + 标明区布局；探针锁死区只做"不破语义"的强化（见 §4）。
3. **触屏优先**：不缩小任何已过 36px 触达矩阵的控件；放大密度靠对比与分组，不靠缩。

### 3.2 新增 token（不改探针，纯新增常量）

| token | 值 | 用途 |
|---|---|---|
| `shadow` | `Color8(0,0,0,70)` | 卡片投影（StyleBoxFlat.shadow_size=10*S, offset y=4） |
| `edge_hi` | `Color8(255,244,214,38)` | 卡片顶缘高光线/按钮顶缘 |
| `edge_lo` | 主色 ×0.55 | 按钮底缘"厚度"（border_width_bottom） |
| `track` | `Color8(10,8,5,220)` | 血条底槽 |
| `warn` | `Color8(180,96,44,255)` | 血条 <30% / 波次警戒 |

### 3.3 组件规格

- **卡片**：圆角 14、border `border` 1px、顶缘 `edge_hi` 1px（border_width_top=1 用亮色 → 双描边）；shadow_size 10*S + shadow_offset(0,4*S)。
- **按钮三态**：normal（btn + edge_lo 底缘 3px）；hover（btn_hover + 上浮变暗=-1px 调 border）；pressed（btn_pressed + 底缘 1px=按下沉）。主按钮同规格换 `active` 底 + `active_border` 边。
- **字阶**（S 缩放同现有）：标题屏大标 54/S + 字距 8；副标 14；卡片题 20；按钮 12–14；正文 11；注释 9。
- **分隔线**：`Color8(92,72,40,120)` 高 1px，宽 220*S。

## 4. 布局重排（C 部分）与探针锁死表

### 4.1 可动区

- **标题屏**：遮罩改渐变 TextureRect（GradientTexture2D：顶部 60α → 底部 190α，保留战场看点）；标题块 = 大标 + 金分隔线 + 副标；按钮列对比节奏（主钮 48h/14 字、次钮 40h/12 字已如此，加 hover 态与宽度统一 240）；footer 移到底缘贴边。
- **顶栏**：分组重排——左组（核心血条+数值）｜中组（波次）｜右组（供给金值大字 + 热层 + 暂停钮组）。用底槽色块分格。
- **血条**：`track` 底槽 + 1px `border` + 主填充 hp 色 + 3 条竖刻度线（25/50/75%）；数值右侧带阴影字。
- **模式列**：选中钮加 `active_border` 亮边 + 文字转白加粗视觉（底色机制不变）；未选中文字用 `muted`。
- **结算**：胜卡标题下水青 + 卡边随胜负换色（胜 `hp`/败 `danger` 顶缘）；统计行改"键 muted / 值 text"两段式，标题下加分隔线。
- **存档**：槽位钮文字色按状态分层（有效=text、空=muted、损坏=warn 暗红）；删除钮高度对齐 36。
- **暂停/设置**：统一卡片规格；设置滑杆列改左标签右值的稳定网格。

### 4.2 锁死区（动 = 连带改探针 + 负对照）

| 锁死物 | 锁死者 |
|---|---|
| `BTN_H=42 / COL_W=128 / CORNER_*` 几何、`hit_regions()` 语义 | `probe_hud` 布局断言、`probe_touch` 22 钮 ≥36px 矩阵、main 点击排除 |
| `set_mode` 机制：normal stylebox bg == `DARK[active]/[btn]` + `sb_normal` 存 meta | `probe_hud._check_btn_color` |
| `FLOAT_LIFE=18` / 浮字 α 算式 | `probe_hud` 浮字断言 |
| 控件名全集（`btn_slot%d`、`btn_confirm_ok`…） | `probe_ui_flow`、`probe_touch`、`probe_save`、`main` |
| `hud.safe` 四元组与 `_layout()` 重算 S | `probe_hud` 安全区/缩放断言（D5-4） |
| 五屏页流转 API（`open_title/open_pause/...`） | `probe_ui_flow`、`main` |

> 本稿布局重排**不触碰锁死区**：顶栏重排在 `TOP_H` 56/`TOP_STRIP_H` 64 与既有控件位置语义内调整分组视觉，不删改几何常量。若实施中发现必须破某条，升级回用户裁决。
