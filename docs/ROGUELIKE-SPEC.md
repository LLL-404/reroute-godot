## 2 一局状态机

```
[TITLE] --选肉鸽--> [LAYER_INTRO] --点开始--> [WAVE_ACTIVE]
                                                    |
                                    波清场 ---------+ 
                                                    v
                                              [INTERMISSION]
                                              （三选一 / 建塔 / 改地形）
                                                    |
                        ┌───────────────────────────┼──────────────────────────┐
                        │ 非层末波                   │ 层末波                    │
                        v                           v                          v
                   [WAVE_ACTIVE]              [LAYER_CLEAR]              [CORE_DEAD]
                                              （层奖励 + 威胁升级）            |
                                                    |                        v
                                         ┌──────────┴──────────┐        [RUN_OVER]
                                         │ 层 < 5              │ 层 = 5
                                         v                     v
                                   [LAYER_INTRO]         [RUN_WON]
```

| 状态 | 玩家可做 | 计时 | 退出行为 |
|---|---|---|---|
| `LAYER_INTRO` | 读威胁预告、看新出怪口位置 | 暂停 | 可回标题（本局作废，需确认） |
| `WAVE_ACTIVE` | 建造 / 拆 / 改地形 / 英雄操作 | 20 Hz 推进 | 暂停菜单只有「放弃本局」 |
| `INTERMISSION` | 三选一、刷新、建塔、改地形 | 暂停 | 同上 |
| `LAYER_CLEAR` | 看结算 | 暂停 | 自动进入下一层 |
| `RUN_WON` / `RUN_OVER` | 查看本局构筑、重开 | 冻结 | 回标题或立即再来 |

**硬规则**：
- MUST 在 `WAVE_ACTIVE` 期间禁用选牌面板（避免战斗中途构筑）。
- MUST NOT 提供任何存档入口；`save_io` 三槽在本模式内全部禁用。
- NEVER 让 `WAVE_ACTIVE` 自动结束；必须「场上无单位」才进 `INTERMISSION`。

## 4 威胁升级（五层的实质）

核心恒在 `(33, 6)`。每层开局对 `Grid` 做一次不可逆改造，同时启用一个新出怪口。

| 层 | 新增出怪口 | 生成规则 | 距核心（格） | 对玩家防线的意义 |
|---|---|---|---|---|
| L1 | 西、东主口 | 沿用 `spawns[0..1]`（y≈56） | ~50 | 现有咽喉防线有效 |
| L2 | 盆地口强制启用 | `spawns` 末位（x≈6, y≈57） | ~51 | 侧翼，逼分兵 |
| L3 | 岩脊爆破口 | 在 `ridge_y=42` 随机 x 打通 1 格 | ~36 | 直接穿破咽喉，老墙阵失效 |
| L4 | 中场裂口 | 在 `y≈21` 随机 x 打通至核心走廊 | ~15 | 纵深防线必须重建 |
| L5 | 核心侧翼裂口 | 在 `y≈12` 打通，距核心 6 格 | ~6 | 只剩贴脸防守 |

**打通算法**（确定性，禁浮点）：
```
1. 选定入口格 P（按层规则 + RNG 抽样）
2. 从 P 向核心走单调阶梯：每步 dx = sign(core.x - x)，dy = 0 或 -1
3. 逐格 set_cell(OPEN)，遇 SOLID 也强制打通（记入 layer_breach 日志）
4. 保证高度沿路径单调不升（下崖任意），必要时压平高度
```

**硬规则**：
- MUST 每层只新增 1 个口，`spawns` 数组只追加不改写。
- MUST 在进入 `LAYER_INTRO` 前完成地形改造与流场全量重建。
- NEVER 在 `WAVE_ACTIVE` 期间改地形（唯一例外：Boss 词缀「腐蚀」，见 §6）。

## 6 Boss 与词缀池

Boss 基座 = `behemoth` 改血量 ×层倍率，占 1 个出怪名额 + 4~6 只随从 `swarm`。

| 词缀 | 效果 | 实现钩子 |
|---|---|---|
| 狂暴 | 血量 <50% 时攻击 cd ×0.5 | `on_tick` |
| 护盾 | 每 5 s 获得吸收 100 伤害的盾 | `on_tick` |
| 分裂 | 死亡时分裂 2 只 50% 血小体 | `on_death` |
| 穿墙 | 无视建筑，直线朝核心走 | `on_move` |
| 拆迁 | 对建筑伤害 ×3 | `on_attack` |
| 献祭 | 每 3 s 召唤 2 只 swarm | `on_tick` |
| 腐蚀 | 走过的格子高度 -1（永久） | `on_move` |
| 荆棘 | 受击时反弹 30% 伤害给攻击塔 | `on_damage` |
| 疾行 | 移速 ×2，血量 ×0.7 | 属性修正 |
| 静滞 | 光环半径 6 内塔攻速 ×0.5 | `on_tick` |

| 层 | Boss 血量倍率 | 词缀数 | 随从 |
|---|---|---|---|
| L1 | ×1.0 | 2 | 4 swarm |
| L2 | ×1.4 | 2 | 4 swarm |
| L3 | ×1.9 | 2 | 5 swarm |
| L4 | ×2.5 | 3 | 5 swarm |
| L5 | ×3.2 | 3 | 6 swarm |

**硬规则**：
- MUST 词缀在 Boss 出生瞬间一次性组装完成，整局不变。
- NEVER 让「穿墙」与「静滞」同层出现（组合下无解）。
- MUST 同一局内 5 个 Boss 的词缀组合两两不同。

## 7 经济

| 项 | 值 | 相对现值 |
|---|---|---|
| 开局供给 | 300 | 不变 |
| 每层开始补给 | +50 | 新增 |
| 层通关奖励 | +60 | 新增 |
| 矿格 | +25 / 格，共 17 格 | 不变 |
| 击杀赏金 | `reward + (traveled >> CONVOY_SHIFT)` | 不变 |
| 刷新 | 30/50/70/90 | 新增 |
| 跳过 | +50 | 新增 |

**设计意图**：5 层总供给 ≈ 300 + 250（层补给）+ 300（层奖励）+ 425（矿）+ 击杀（约 200×5 均 8 ≈ 800）= **约 2075**，而 8 种塔单价 40–110。玩家能建约 25–35 座，平均 5–7 座/层 —— 配合「建筑全保留」，后期塔位比钱更紧。

**硬规则**：
- MUST NOT 让供给可跨层结算（每层独立，未花完的不清零但也不额外给）。
- MUST 在建塔时校验塔位合法性（沿用 `apply_command` 守卫）。

## 8 验收

### 8.1 固定种子回放

| 项 | 做法 |
|---|---|
| 随机源 | `run_seed = BASE_SEED + run_index`，抽卡用 `(run_seed, wave_index, pick_index)` 派生，不共享仿真 RNG |
| 刷新 | 刷新消耗 `(run_seed, wave_index, refresh_count)` 派生，仍在种子内 |
| 重放粒度 | 玩家输入序列（命令流）录入 → 回放至指纹一致 |
| 指纹采样点 | 每层开始 / 每波结束 / 每 Boss 死亡 / 通关，共约 25 条 |
| 基线文件 | `sim/run_golden_baseline.gd`（**新建**，与现有 16 指纹并列，互不影响） |

### 8.2 跑批

| 项 | 做法 |
|---|---|
| 入口 | `tools/batch_run.gd`（headless） |
| 局数 | 500 |
| 玩家 | **固定策略 bot**：塔优先建在流场高流量格、有钱先建箭塔、三选一按预设优先级取 |
| 输出 | 胜率、平均通关层、每层死亡率、每张卡选取率、每张卡胜率贡献 |
| 合格线 | 首版胜率 35–50%；任一张卡选取率 >70% 或 <5% 视为失衡 |

### 8.3 老闸处置

| 闸 | 处置 |
|---|---|
| 现有 16 指纹 + 剧本指纹 | **不动**，老模式继续跑 |
| 单测 104 例 | 保留，新增 run 层单测 |
| 21 道验收探针 | 保留，新增 `probe_rogue_*` |
| `selfcheck` 33 项 | 追加肉鸽模式入口自检 |

**硬规则**：
- NEVER 为让新模式探针变绿而修改老基线。
- MUST 老模式下 `World.btab` 恒指向 `Sim.BUILDINGS`，保证 16 指纹零漂移。

**目标**：把 PICK 阶段的横排小卡换成《英雄联盟》强化选择那种"全屏、悬浮、发光"的手感。

### 15.1 实现

| 阶段 | 表现 | 参数 |
