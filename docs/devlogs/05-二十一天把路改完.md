二十一天到站。这一期不加新机制，做一次完整复盘：从「放墙改道」这一条规则，到真正能下载、能试玩的双端包。

【本期进展】

收尾这一段，我们把所有零件合上了。双端包终版：Windows 自签可执行文件 + 资源包（自检全绿），Android release 包（接入 TapPlay、选通用隐私协议），商店五图、简介、推荐语、更新日志与平台物料全部就位并提交审核。

四个收尾增量：开屏动画（晶体特写 + 金衬线「改道」逐字入场，可任意键跳过）；设置 v3（音频 / 显示 / 画质 / 性能四组，PC 高画质不限帧、安卓中画质 60 帧的平台默认）；世界生成 2.0（玩法层自由化——自由核心位、2~3 个出怪口、盆地与岩野，默认种子仍字节冻结）；地形自然化（填挖落差边变成可爬缓坡与层理岩壁，颜色和形状直接告诉你路在哪）。

底座也在：64×64 六边格、确定性模拟（16 个黄金指纹锁死行为）、106 条单测 + 22 个验收探针、30 个音效、9 件模型（含四级 LOD）。

【问题与风险】

最大的不确定项是审核时长：商店审核什么时候过，我们控制不了。做法是提前把包和素材备齐、先提审，过审后第一时间完成活动页投稿；如果审核延后，以最后一次过审的版本为准。

另一个取舍：世界生成 2.0 的视觉联动（岩脊、山体随自由布局变化）还没做完，本次先以 10-18 版提审，联动更新留到上线后。

【下期计划】

试玩体验打磨：新手引导、难度曲线、性能与发热；补齐自由生成的视觉联动；把大家在评论区和活动页留下的反馈，做成下一版更新日志。

双端已经开放试玩。欢迎下载后贴出你的「改道」路线截图——你为敌人改的那条路，就是我们最想看到的作品。
